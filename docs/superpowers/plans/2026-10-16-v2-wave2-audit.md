**Spec:** `docs/superpowers/specs/2026-10-16-v2-wave2-audit-design.md`; API shapes are the TS types in `frontend/src/lib/api.ts` (TrustAudit … LedgerExport), field for field.

## Rulings where the spec is silent
- `terms.*_pct` are percent strings ("25" = 25%); fee = amount × pct / 100. Cost if wrong: fee off by 100× (one divisor).
- `engines[]` on a run = the engines that run; others are `off` for that run (never changes the tenant setting). Empty = all four. Cost if wrong: a one-engine re-run also re-runs the rest (slower, same findings).
- Requesting a run moves a `draft` audit to `active`. Cost if wrong: one line.
- Period filter excludes a finding whose transaction carries no date. Cost if wrong: undated findings invisible to a scoped engagement; flip one branch.
- `accepted_impact` = Σ impact of scope findings in accepted|claimed|recovered|prevented|written_off. `at_risk_holds` = Σ impact of open hold findings in scope. `top_recoveries` = scope findings not rejected/written_off, by impact desc, ≤20.
- Ledger rows = scope events with `to_status` in claimed|recovered|prevented|written_off (the CSV is the recovery trail; totals carry claimed as the frontend type does).
- A stale run (`queued` > 30 min, `running` > 2 h) is marked `failed`/"abandoned" when the next run is requested (review item M6).
