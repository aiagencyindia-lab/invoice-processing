# SSO (Domain-bound Google Sign-in) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tenant admin binds an email domain to Google; staff from that domain sign in with their work account and are provisioned with a default role; role changes and deactivation take effect on the next request.

**Architecture:** A new `sso_domains` table (tenant-scoped, RLS, plus one read-only lookup policy for the pre-tenant domain lookup) and two columns on `users` (`uid`, `last_login_at`). A pure resolver in `invoice_processing/sso.py` decides a request's principal from the verified claims and a small `UserDirectory` port; `api/auth.py` wires it in behind one provider hook so tests fake it without a database. Admin routes manage domains and user role/active state. The frontend gains an SSO panel and per-user controls.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2, Alembic (SQLite locally, Postgres with forced RLS in CI/prod); Next.js 16; Playwright. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-12-sso-design.md` (amended in Task 1; read it before every task).

## Global Constraints

- Always run Python as `./.venv/bin/python` from the repo root. Tests: `./.venv/bin/python -m pytest <file> -q -p no:cacheprovider`. Lint: `./.venv/bin/python -m ruff check . && ./.venv/bin/python -m ruff format .`
- TDD: write the test, see it fail for the expected reason, then implement; record RED and GREEN.
- The tenant comes from the signed token and from nowhere else. No endpoint takes `tenant_id`. Every repository query filters `tenant_id` explicitly except the single pre-tenant domain lookup, which runs under the `sso-lookup` sentinel.
- Resolution order: (1) token has `tenant_id` → tenant = claim; users row read; inactive → 403 "This account has been deactivated. Ask an admin of <tenant name> to reactivate it."; row role overrides claim role; no row → claim role. (2) no tenant claim → `email_verified` true and `firebase.sign_in_provider == "google.com"` required; Microsoft → 403 "Microsoft sign-in is not enabled yet."; domain looked up; no match → existing 403 "Token carries no tenant_id claim…"; match → link or create row (role = default_role), write claims, audit `user_provisioned_by_sso`. (3) no database → claims only. Dev bypass: active check only, header role kept.
- Public mailbox domains refused: gmail.com, googlemail.com, outlook.com, hotmail.com, live.com, yahoo.com, icloud.com, proton.me, protonmail.com.
- `domain` is globally unique; a domain held by another tenant → 409 "That domain is already connected to another organisation." with no hint which.
- Admin cannot demote or deactivate themself (409). Audit names: `sso_domain_added`, `sso_domain_removed`, `user_role_changed`, `user_deactivated`, `user_reactivated`, `user_provisioned_by_sso`. `_ENTITY_TYPES` gains `sso_domain`.
- Never edit an applied migration; new head revises `b8c4d1e2f3a5`; `RLS_TABLES = ["sso_domains"]`.
- New routes get a cross-tenant probe + `PROBED` entry; the module goes in `test_no_endpoint_reads_a_tenant_from_the_request`; new DB test files go on the CI Postgres list.

```python
# ---------------------------------------------------------------------------
# Sign-in: who is who, and which domains may sign in where
# ---------------------------------------------------------------------------


class DomainTaken(Exception):
    """Another tenant already holds this domain."""


def _user_dict(u: User, tenant_name: str | None) -> dict:
    return {
        "id": u.id,
        "email": u.email,
        "role": u.role,
        "is_active": bool(u.is_active),
        "uid": u.uid,
        "display_name": u.display_name,
        "last_login_at": u.last_login_at,
        "tenant_name": tenant_name,
    }


class PgUserDirectory:
    """The users rows as the request path reads them.

    Small on purpose: `find` is on every authenticated request, so it is one
    indexed read; the writes happen once per sign-in at most.
    """

    def __init__(self, url: str | None = None):
        self.url = url

    @staticmethod
    def _tenant_name(session, tenant_id: str) -> str | None:
        return session.scalar(select(Tenant.name).where(Tenant.id == tenant_id))

    def find(self, tenant_id: str, email: str) -> dict | None:
        wanted = (email or "").strip().lower()
        with tenant_session(tenant_id, self.url) as session:
            row = session.scalar(
                select(User).where(
                    User.tenant_id == tenant_id,
                    func.lower(User.email) == wanted,
                )
            )
            if row is None:
                return None
            return _user_dict(row, self._tenant_name(session, tenant_id))

    def _row(self, session, tenant_id: str, user_id: str) -> User:
        row = session.scalar(
            select(User).where(User.tenant_id == tenant_id, User.id == user_id)
        )
        if row is None:
            raise LookupError(user_id)
        return row

    def link_uid(self, tenant_id: str, user_id: str, uid: str) -> None:
        with tenant_session(tenant_id, self.url) as session:
            self._row(session, tenant_id, user_id).uid = uid

    def touch_login(self, tenant_id: str, user_id: str, now: datetime) -> None:
        with tenant_session(tenant_id, self.url) as session:
            self._row(session, tenant_id, user_id).last_login_at = now

    def provision(
        self, tenant_id: str, email: str, role: str, uid: str | None,
        display_name: str | None,
    ) -> dict:
        with tenant_session(tenant_id, self.url) as session:
            row = User(
                tenant_id=tenant_id,
                email=email.strip().lower(),
                role=role,
                uid=uid,
                display_name=display_name,
            )
            session.add(row)
            session.flush()
            return _user_dict(row, self._tenant_name(session, tenant_id))

    def set_role(self, tenant_id: str, user_id: str, role: str) -> dict:
        with tenant_session(tenant_id, self.url) as session:
            row = self._row(session, tenant_id, user_id)
            previous, row.role = row.role, role
            session.flush()
            return {**_user_dict(row, None), "previous_role": previous}

    def set_active(self, tenant_id: str, user_id: str, active: bool) -> dict:
        with tenant_session(tenant_id, self.url) as session:
            row = self._row(session, tenant_id, user_id)
            previous, row.is_active = bool(row.is_active), active
            session.flush()
            return {**_user_dict(row, None), "previous_active": previous}

    def domain(self, domain: str) -> dict | None:
        """Which tenant owns this domain. Runs before a tenant is known, so
        under the lookup sentinel; see rls.SSO_LOOKUP_TENANT."""
        from .rls import SSO_LOOKUP_TENANT  # noqa: PLC0415

        wanted = (domain or "").strip().lower()
        with tenant_session(SSO_LOOKUP_TENANT, self.url) as session:
            row = session.scalar(
                select(SsoDomain).where(SsoDomain.domain == wanted)
            )
            if row is None:
                return None
            return {
                "id": row.id,
                "tenant_id": row.tenant_id,
                "tenant_name": self._tenant_name(session, row.tenant_id),
                "domain": row.domain,
                "provider": row.provider,
                "default_role": row.default_role,
            }


class PgSsoDomainRepository:
    """A tenant's own domain bindings. The API validates; this stores."""

    def __init__(self, url: str | None = None):
        self.url = url

    @staticmethod
    def _dict(d: SsoDomain) -> dict:
        return {
            "id": d.id,
            "domain": d.domain,
            "provider": d.provider,
            "default_role": d.default_role,
            "created_by": d.created_by,
            "created_at": _iso(d.created_at),
        }

    def list(self, tenant_id: str) -> list[dict]:
        with tenant_session(tenant_id, self.url) as session:
            rows = session.scalars(
                select(SsoDomain)
                .where(SsoDomain.tenant_id == tenant_id)
                .order_by(SsoDomain.domain)
            )
            return [self._dict(d) for d in rows]

    def add(
        self, tenant_id: str, *, domain: str, provider: str,
        default_role: str, created_by: str,
    ) -> dict:
        try:
            with tenant_session(tenant_id, self.url) as session:
                row = SsoDomain(
                    tenant_id=tenant_id,
                    domain=domain.strip().lower(),
                    provider=provider,
                    default_role=default_role,
                    created_by=created_by,
                )
                session.add(row)
                session.flush()
                return self._dict(row)
        except IntegrityError as exc:
            # The unique constraint is the arbiter; a check-then-insert would
            # let two admins race for the same domain.
            raise DomainTaken(domain) from exc

    def remove(self, tenant_id: str, domain_id: str) -> bool:
        with tenant_session(tenant_id, self.url) as session:
            row = session.scalar(
                select(SsoDomain).where(
                    SsoDomain.tenant_id == tenant_id, SsoDomain.id == domain_id
                )
            )
            if row is None:
                return False
            session.delete(row)
            return True
```

```python
"""Who a verified token is, once the users table has a say.

The tenant still comes from the signed token and from nowhere else. What this
module adds is the users row's word on role and active status, and the one
path by which a token with no tenant yet can earn one: a verified company
address whose domain an admin bound to this tenant.
"""

from __future__ import annotations

import logging
import re
from datetime import datetime, timedelta, timezone
from typing import Any, NamedTuple

from .api.auth import AuthError, Principal, principal_from_claims

logger = logging.getLogger(__name__)

PUBLIC_MAILBOX_DOMAINS = frozenset(
    {
        "gmail.com", "googlemail.com", "outlook.com", "hotmail.com",
        "live.com", "yahoo.com", "icloud.com", "proton.me", "protonmail.com",
    }
)
_DOMAIN = re.compile(r"^(?=.{1,253}$)([a-z0-9](?:[a-z0-9-]{0,61}[a-z0-9])?\.)+[a-z]{2,63}$")
# ponytail: one write per quarter hour; sharpen if anyone needs minute-level last-seen.
LOGIN_TOUCH = timedelta(minutes=15)
GOOGLE = "google.com"
MICROSOFT = "microsoft.com"


class SsoServices(NamedTuple):
    directory: Any  # PgUserDirectory-shaped
    claims: Any  # ClaimsWriter
    audit: Any  # AuditSink


def normalize_domain(value: str) -> str:
    domain = (value or "").strip().lower()
    if not _DOMAIN.match(domain):
        raise ValueError(f"{value!r} is not a domain name.")
    if domain in PUBLIC_MAILBOX_DOMAINS:
        raise ValueError(
            f"{domain} is a public mailbox provider; anyone can get an address "
            "there, so it cannot identify an organisation."
        )
    return domain


def domain_of(email: str) -> str:
    return (email or "").rpartition("@")[2].strip().lower()


def _unavailable(exc: Exception) -> AuthError:
    logger.error("Sign-in needs the users directory and could not read it: %s", exc)
    return AuthError(
        "Sign-in needs a database that could not be reached. Try again shortly.",
        status_code=503,
    )


def _refuse_inactive(row: dict) -> None:
    if row.get("is_active") is False:
        raise AuthError(
            "This account has been deactivated. Ask an admin of "
            f"{row.get('tenant_name') or 'your organisation'} to reactivate it.",
            status_code=403,
        )


def _touch(services: SsoServices, row: dict, now: datetime) -> None:
    last = row.get("last_login_at")
    if last is not None and last.tzinfo is None:
        last = last.replace(tzinfo=timezone.utc)
    if last is None or now - last >= LOGIN_TOUCH:
        try:
            services.directory.touch_login(row["tenant_id"], row["id"], now)
        except Exception as exc:  # a lost timestamp must not cost a request
            logger.warning("last_login_at not updated for %s: %s", row.get("email"), exc)


def enforce_active(principal: Principal, services: SsoServices | None) -> Principal:
    """Refuse a deactivated row; keep the principal's own role (dev bypass)."""
    if services is None:
        return principal
    try:
        row = services.directory.find(principal.tenant_id, principal.email)
    except Exception as exc:
        raise _unavailable(exc) from exc
    if row is not None:
        _refuse_inactive(row)
    return principal


def resolve_principal(
    claims: dict[str, Any], services: SsoServices | None, now: datetime | None = None
) -> Principal:
    now = now or datetime.now(timezone.utc)
    if claims.get("tenant_id") or claims.get("tenantId"):
        base = principal_from_claims(claims)
        if services is None:
            return base
        try:
            row = services.directory.find(base.tenant_id, base.email)
        except Exception as exc:
            raise _unavailable(exc) from exc
        if row is None:
            return base
        _refuse_inactive(row)
        _touch(services, {**row, "tenant_id": base.tenant_id}, now)
        return Principal(
            user_id=base.user_id, email=base.email,
            tenant_id=base.tenant_id, role=str(row["role"]),
        )

    # No tenant yet: the only way in is a bound company domain.
    if services is None:
        return principal_from_claims(claims)  # raises the usual 403
    email = str(claims.get("email") or "").strip().lower()
    if not email:
        raise AuthError("Token carries no email claim.", status_code=403)
    if claims.get("email_verified") is not True:
        raise AuthError("Email address is not verified.", status_code=403)
    provider = (claims.get("firebase") or {}).get("sign_in_provider")
    if provider == MICROSOFT:
        raise AuthError("Microsoft sign-in is not enabled yet.", status_code=403)
    if provider != GOOGLE:
        return principal_from_claims(claims)  # raises the usual 403
    try:
        bound = services.directory.domain(domain_of(email))
    except Exception as exc:
        raise _unavailable(exc) from exc
    if bound is None:
        return principal_from_claims(claims)  # raises the usual 403

    tenant_id = bound["tenant_id"]
    uid = str(claims.get("user_id") or claims.get("sub") or "")
    try:
        row = services.directory.find(tenant_id, email)
        if row is None:
            row = services.directory.provision(
                tenant_id, email, bound["default_role"], uid or None,
                (claims.get("name") or None),
            )
            created = True
        else:
            _refuse_inactive(row)
            if not row.get("uid") and uid:
                services.directory.link_uid(tenant_id, row["id"], uid)
            created = False
    except AuthError:
        raise
    except Exception as exc:
        raise _unavailable(exc) from exc

    principal = Principal(user_id=uid, email=email, tenant_id=tenant_id, role=str(row["role"]))
    if uid:
        try:
            services.claims.set_claims(uid, {"tenant_id": tenant_id, "role": row["role"]})
        except Exception as exc:
            # The row is the authority now; the next request writes the claim.
            logger.warning("Claims not written for %s: %s", email, exc)
    if created:
        services.audit.emit(
            principal.context(),
            "user_provisioned_by_sso",
            {"email": email, "role": row["role"], "domain": bound["domain"]},
        )
    _touch(services, {**row, "tenant_id": tenant_id}, now)
    return principal
```

```python
def add_sso_domain(
    request: SsoDomainCreate,
    principal: Annotated[Principal, Depends(require_role("admin"))],
) -> dict:
    """Let a company's verified accounts sign in here.

    No proof of ownership: a bound domain admits only Google-verified
    accounts of exactly that domain, and Google verifies only addresses it
    hosts, so binding a domain you do not own admits nobody.
    """
    from .. import sso  # noqa: PLC0415
    from ..db.repositories import DomainTaken  # noqa: PLC0415
    from . import service  # noqa: PLC0415

    try:
        domain = sso.normalize_domain(request.domain)
    except ValueError as exc:
        raise HTTPException(status_code=422, detail=str(exc)) from exc
    try:
        record = _sso_domains().add(
            principal.tenant_id,
            domain=domain,
            provider=request.provider,
            default_role=request.default_role,
            created_by=principal.email,
        )
    except DomainTaken:

        raise HTTPException(
            status_code=409,
            detail="That domain is already connected to another organisation.",
        ) from None
    service.get_audit().emit(
        principal.context(),
        "sso_domain_added",
        {"domain": domain, "provider": request.provider, "default_role": request.default_role},
    )
    return record
```
